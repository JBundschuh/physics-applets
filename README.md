# physics-applets
**(EN)**
Interactive physics web applets for physics education. Developed using Python (PyScript), JavaScript, HTML, and CSS. Freely available to support the visualization of physics concepts and encourage customization and further development.

**(DE)**
Interaktive Physik-Webapplets für den Physikunterricht. Entwickelt mit Python (PyScript), JavaScript, HTML und CSS. Frei verfügbar, um physikalische Konzepte anschaulich zu vermitteln und eigenständig zu erweitern.
